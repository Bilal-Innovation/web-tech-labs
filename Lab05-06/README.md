# Lab 05 & 06 - CSS Layout & Responsive Design

This lab focuses on different CSS layout techniques and responsive design concepts.  
All tasks are implemented using separate HTML and CSS files.

## 📁 Folder Structure

- **styles/** → Contains all CSS files  
- **exercises/** → Basic CSS concepts (Display, Float, Position, Flexbox)  
- **layouts/** → Advanced layouts (Grid, Holy Grail, Dashboard, Media Queries)  

## 🧪 Topics Covered

- Display Properties (block, inline, inline-block)
- Float Layouts
- CSS Positioning (fixed, relative, absolute, sticky)
- Flexbox (navigation and cards)
- CSS Grid (gallery and product layout)
- Responsive Design using Media Queries

## 📱 Responsive Design

Media queries are used to adjust layouts for:
- Mobile
- Tablet
- Desktop

## ▶️ How to Run

1. Open `index.html`
2. Navigate to any section (Exercises / Layouts)
3. Open files in browser to view output

Each task has:
